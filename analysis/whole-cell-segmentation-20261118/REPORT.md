# 細胞全体のセグメンテーション研究と Cell Review への統合（2026-11-18）

## 0. 結論

- **IF は部分的に成功しました。**
  - 方式は Cellpose-SAM（cpsam）で、入力は表示用 RGB から作った膜マーカーの代用（G+R = Dystrophin + Desmoplakin）です。
  - これで心筋細胞の外形をおおむね取れました。
  - 031-8_6（横断面が多い）は概ね妥当です。評価 ROI で、組織の 57〜84% が細胞で覆われました。
  - 031-6_2（斜め〜縦断面）は部分的です。組織の 12〜56% しか覆われず、輪郭のない領域が多く残りました。
  - 間質の細胞（心筋の間の小さい核）は、ほぼ取れていません。
  - この方式（`S1_cpsam_if_mem_full`）を IF 切片全体に適用し、Cell Review で表示できるようにしました。
- **H&E は失敗しました。**
  - Cellpose-SAM に H&E の RGB をそのまま入れると、**核だけ**を分割しました。細胞の 57〜70% が核とほぼ同じ大きさでした。
  - エオシンだけを入れると、ほとんど何も検出しませんでした。組織の 2〜5% しか覆われていません。tuning ROI の 1 つだけで局所的にうまくいきましたが、評価 ROI では再現しませんでした。
  - 核を種にした Watershed は、境界が画像に部分的にしか合いません。
  - **H&E で細胞全体の輪郭を取れた方式はありません。**
- **Mesmer は実行できていません。**
  - 導入はできました（DeepCell 0.12.10）。
  - しかし重みの取得に `DEEPCELL_ACCESS_TOKEN` が必要で、未設定のため取得できませんでした。
  - 成功したとは扱っていません。
- **Voronoi（距離だけで分けたもの）は基準線です。** どの評価でも、細胞の検出結果としては数えていません。
- **正解の輪郭はありません。** ここにある数値は、核との関係・画像の境界信号との一致・目視による代理の評価で、精度ではありません。
  - 手動評価の表（manual_eval/template.csv、380 細胞）を用意しましたが、まだ記入されていません。
- **Cell Review で細胞輪郭を表示できるようにしました（研究モード、既定オフ）。**
  - 核の中心点・核輪郭とは別のデータとして扱います。
  - 表示は破線・オレンジで、核輪郭（実線）と区別できます。
  - 表示の切替が独立していて、方式を選べます（使えない方式は理由を表示）。
  - 左右比較にも表示し、判定と一緒に方式・版・細胞 ID・細胞の所見を記録できます。
- **既存の動作は変えていません。**
  - 核の中心点・核輪郭・Workflow C/D・Graph/UOT/B2・RBF・画像の変形は変わっていません。
  - 確認方法は 2 つです。保護した 42 ファイルの sha256 を照合し、変更前のコードと数値が一致することをテストしました。

## 1. 監査（詳細は audit.md）

- **IF:** 生の蛍光チャンネルは無く、8 bit の表示用 RGB だけです（R = Desmoplakin、G = Dystrophin1、B = Hoechst + Desmoplakin）。
- **H&E:** RGB です。心筋の細胞境界は淡い隙間としてしか見えません。031-6_2 ではほとんど見えません。
- **既存のセグメンテーション:** すべて核です（H&E は StarDist、IF は提供元のもの）。細胞全体のデータはありませんでした。
- 膜関連マーカーが**ある**ことと、細胞境界を**正確に取れる**ことは別問題として扱いました。Dystrophin は心筋細胞しか囲まないので、間質の細胞は対象外になります。

## 2. 方式と条件

- **処理の範囲:**
  - ROI を 0.5 µm/画素に作り直して処理しました（IF は 5 倍、H&E は 2.65 倍の縮小）。150 µm 四方なので 300×300 画素です。
  - level 0 の全体は読み込んでいません。
  - 切片全体（IF の 1026 µm 四方 = 2052×2052 画素）は、Cellpose 内部の重なりのあるタイル処理で一度に処理しました。

| ID | 方式 | 入力 | 対象 |
|---|---|---|---|
| S0 | 既存の核輪郭（基準） | — | H&E・IF |
| S1 `he_rgb` | Cellpose-SAM（cpsam）、既定の設定 | H&E RGB | H&E |
| S1 `he_eosin` | 同上 | H&E エオシン OD（色分解） | H&E |
| S1 `if_rgb` | 同上 | IF 表示 RGB そのまま | IF |
| S1 `if_mem` | 同上 | **G+R（膜の代用）** だけ | IF |
| S2 | Mesmer whole-cell | 核 = clip(B−R)、膜 = G+R（**どちらも表示 RGB からの代用**） | IF のみ（H&E は明視野なので対象外） |
| S3 watershed | 既存の核を種、境界信号の上で Watershed、組織マスク内、種から 25 µm まで | IF は G+R、H&E は 1−エオシン | H&E・IF |
| S3 voronoi | 既存の核を種、距離だけ（expand_labels）、組織マスク内、25 µm まで | 画像を使わない | **基準線（検出ではない）** |

- **Cellpose のパラメータ選び:** tuning ROI（各サンプル 2 つ、評価 ROI とは別）を目で見て選びました。
  - 試した組み合わせ: 6 種類の入力 × 等倍 / 2 倍拡大、cellprob 0 / −2。
  - 2 倍に拡大しても、cellprob を −2 にしても改善しませんでした。
  - `if_rgb` と `if_memnuc`（膜 + 核の 2 チャンネル）は核を優先して分割しました。
  - `if_mem` は細胞の外形を取りました。
  - 採用した設定: cellprob 0、flow 0.4、等倍。
- 評価 ROI の結果を見てから、方式やパラメータを変えてはいません。

## 3. ROI（rois.json、Phase 2）

- **大きさと分類:** 各サンプルに 150 µm 四方の評価 ROI が 6 つあり、カテゴリは次のとおりです。
  - stardist_suspect: H&E の StarDist 核のうち、内側と周囲のヘマトキシリン比が低い（誤検出の疑い）ものが多い領域
  - dense / sparse: 核の密度で決めた密な領域・まばらな領域
  - clear_boundary / unclear_boundary: 境界の稜線スコアで決めた、境界が明瞭な領域・不明瞭な領域
  - tissue_edge: 組織の端
- tuning ROI は各サンプル 2 つで、評価 ROI と重ならない位置から乱数（seed 0）で選びました。
- 選んだ基準と座標は `roi_select.py` と `rois.json` にあります（座標は IF の frame の µm）。

### 結果の読み方

1. **IF の if_mem だけが「細胞全体」の形をしていました。**
   - 核大がほぼ 0 です。
   - 面積の中央値は 031-8_6 で 528 µm²（評価 ROI）、切片全体で 742 µm² でした。心筋細胞の横断面として妥当な大きさです。
   - 境界比は 12/12 の ROI で Voronoi より高く、予測した境界が膜の信号の上にあることを示しています。
   - 目で見ても、031-8_6 では輪郭が Dystrophin の線に沿っていました（figures/zoom_full_section_if_mem.jpg、cmp_031-8_6_*_IF.jpg）。
2. **031-6_2 の if_mem は不完全でした。**
   - unclear_boundary と tissue_edge では、被覆が 0.12〜0.14 しかありませんでした。
   - 縦断面の心筋は膜の線が切れ切れで、閉じた輪郭になりません。
   - 水平の継ぎ目（y≈632 µm）に沿って、不自然な輪郭が出ました（失敗例。zoom 図の右下）。
3. **if_rgb と he_rgb は核を分割しているだけでした**（核大 0.3〜0.7）。細胞全体としては失敗です。
4. **Watershed の境界比が最も高いのは、作り方による結果です。**
   - Watershed は境界信号の稜線の上に境界を引くので、境界比は高くなって当然です。正しさの根拠にはなりません。
   - 目で見ると、膜の無い場所（間質・隙間）にまで領域が広がっています。輪郭が細胞の中を横切る所もあります（cmp_*_IF.jpg）。
   - 部分的な参考にとどめます。
5. **H&E は全方式で失敗しました。**
   - he_eosin は 8_6 tune_1 では心筋の外形らしいものを取りました。
   - しかし評価 ROI では、検出がほとんど無いか、空胞を拾いました。
6. **間質の細胞は取れていません。** これは Dystrophin が間質の細胞を囲まないためです（予想どおり）。

- **核の無い細胞が多い理由:** 心筋細胞の核は中央に 1〜2 個あるだけなので、薄い切片では核が写らない断面が多くなります。
- **複数核の細胞の中身:** 次の 3 つが混ざっています。真に 2 核の心筋細胞、隣の間質の核が輪郭に入ったもの、細胞の結合（過少分割）です。区別はレビューで行います。
- **中心が細胞外・細胞なしの核:** 主に間質の細胞です。
- 1 核 = 1 細胞には**していません**。核の ID は元の値のまま使っています（振り直していません）。

## 5. Cell Review での使い方（研究モード、`CELLREG_CELL_REVIEW=1`）

1. **方式を選ぶ:**
   - 「2. 核対応の推定と手動レビュー」→「細胞全体の輪郭（研究・既定は表示しない）」で、H&E と IF それぞれの方式を選びます。
   - 既定は「表示しない」です。
   - 使えない方式には（利用不可）と表示し、理由を出します。例: Mesmer は「DEEPCELL_ACCESS_TOKEN が必要」、IF 専用の方式は H&E では使えない、結果ファイルが無い。
   - 「比較のため重ねる方式」で別の方式を細い破線（別の色）で重ねられます。
2. **全体ビューアー:**
   - 表示の切替は独立しています。
     - 核輪郭（実線）
     - 核 ID
     - 核中心点
     - 細胞全体の輪郭（**破線・オレンジ**、核輪郭より低い倍率から表示）
     - 細胞 ID
   - 自動の対応線・手動の対応線は、これまでどおり層として切り替えます。
   - 選択中の核を含む細胞は、太い破線で強調します。H&E は橙、IF は濃い橙、候補の IF 核の細胞は薄い橙です。
3. **左右比較:**
   - 「細胞輪郭（破線）」「細胞 ID」の切替を追加しました。
   - 左右とも、それぞれの切片の元画像（変形していないもの）の上に表示します。
   - 比較中の IF 核を含む細胞は太い破線、周辺の細胞は薄い破線で表示します。
   - RGB の表示、拡大範囲、位置の同期、ズーム・パンは、これまでと共通です。
4. **判定と一緒に記録する内容:**
   - 細胞輪郭を表示しているときは、「輪郭の信頼度」（未評価 / 輪郭は妥当 / 一部妥当 / 信頼できない）、「細胞の所見」（細胞セグメンテーション異常・核と細胞の対応が不一致・細胞境界が不明瞭）、細胞についてのコメントを入力できます。
   - 判定のボタンを押すと、表示していた方式・版・sha256・**その核を含む細胞の ID**（H&E と IF それぞれ）と一緒に、verdict の `cell` に保存します。
   - 核の対応先は変わりません。
   - 保存形式:
     - `cell` の記録があるときだけ `cellreg-cell-review-edits/3` になり、無いときは従来どおり /2 です。
     - /1 と /2 の読み込みは変わりません。
     - 注釈の表（CSV）に `cell_*` の列を 11 個追加しました。古いレビューでは空欄です。
5. **画像の無いサンプル:** 細胞の結果が無いサンプルではすべての方式が利用不可になり、従来どおり核中心点でレビューできます。

## 6. 対応付けに使えそうな細胞の特徴（Phase 5、features.py、Graph/UOT は変更なし）

- **IF の細胞ごとに計算した特徴**（features_if_cells.csv）:
  - 面積、アスペクト比、solidity
  - 核/細胞の面積比、核中心のずれ（等価半径に対する比）
  - 最も近い細胞までの距離、接している細胞の数
- 031-8_6 の中央値: 面積 742 µm²、核/細胞の面積比 0.20、接している細胞 3 個、最近傍の細胞まで 23 µm。
- **確認済みの対応と否定・保留の比較はまだできません。** 人のレビューがまだ無いためです。
- **代わりの比較（代理）:** アルゴリズムの 1 位候補と他の候補で、IF 側の細胞の特徴を比べました。差はありませんでした（例: 031-8_6 の面積は 1020 対 1016 µm²、核/細胞比は 0.196 対 0.208）。
- **効かない理由:**
  - H&E 側に細胞輪郭が無く、細胞と細胞の特徴を比べられません。
  - 031-8_6 は隣り合う切片なので、同じ細胞が両方に写るとは限りません。
  - **現時点では、Graph/UOT に入れる根拠はありません。**
- **将来の候補（H&E 側の細胞輪郭が得られた場合）:**
  - 細胞の面積比
  - 核/細胞比の差
  - 接触グラフ（隣の細胞の数・配置）の一致
  - レビューで「確認」と「否定」が集まったら、この特徴でどこまで分けられるかを先に評価します。
