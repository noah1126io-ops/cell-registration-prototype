# 失敗の分析（2026-11-13）

数値は `rerank_summary.csv`、`candidate_comparison.csv`、`correspondence_results.csv`、`deformation_comparison.csv` から取った（`collect.py` で再計算できる）。
「正しい領域」の定義は experiment_protocol.md §3.4 のとおり（SYN-C1：grid 誤差 ≤ 20 µm、REAL-D：probe ≤ 100 µm）。

## 1. Phase 1：再評価で救えなかったケース

### 1.1 正しい領域が候補（上位 6 件）に入っていない（いちばん多い原因）
SYN-C1 の 39 件のうち、C1 の 1 位が誤ったのは 16 件。そのうち 15 件は、**正しい領域が上位 6 件のどこにも入っていなかった**。

| 条件 | 件数 | 上位 6 件に正解あり |
|---|---|---|
| absent（負例：正しい領域が存在しない） | 3 | 0 |
| overlap=0.3 | 3 | 0 |
| repeat=0.8 | 3 | 0 |
| repeat=1 | 3 | 0 |
| repeat=0.5（seed 1003） | 1 | 0 |
| grid ratio=0.25 ＋ ns=0.85 | 3 | 1（seed 1002、C1 の 3 位） |

- 並べ替えは候補の中から選ぶだけなので、候補に正解がなければ救えない。ボトルネックは「選び方」ではなく「候補の作り方」である。
- REAL-D の 8_6 系も同じ傾向。points 側の上位 6 件には正しい領域が一度も入らず、正しい候補は image 側の 1 位だけだった。
- 実験 C-K30（細かい段階の候補を 6→30 件に広げる。設定の上書きだけで、本番の既定値は変えない）：
  - 21 件のうち、候補に正解が入るケースは 6 件から 9 件に増えた。救済は 1 件（repeat=0.5 seed 1003）。
  - repeat=0.8 / 1、overlap=0.3、absent では、30 件に広げても正解は入らなかった。粗い段階の時点で落ちている（REPORT.md §4）。
  - K30 の repeat=1 でも、誤った候補で C / E の局所変形が適用された（seed 1001 はアンカー 348 個、seed 1002 は 20 個でちょうど下限）。

### 1.2 正しい候補はあったが、主指標が選ばなかった（1 件）
`grid_ratio=0.25_ns=0.85__1002`：正しい候補は C1 の 3 位（points#2）。

| 候補 | 正しい領域 | 重なりの Moving の核 | B2 採択率 | decoy | 主指標（差） | graph support 中央値 |
|---|---|---|---|---|---|---|
| points#1 | × | 170 | 0.059 | 0.012 | **0.047**（1 位） | 0.202 |
| points#2 | ○ | 352 | 0.034 | 0.011 | 0.023（2 位） | **0.250**（1 位） |

- ns=0.85（Moving の核の 85% が Fixed 側にない）なので、正しい候補でも B2 の採択率は 3.4% しかない。B2 の precision は 0.5 にとどまった。
- 誤った候補との差は偶然の範囲に入る。主指標は 0.10 に届かず「支持されない」と正しく判定され、実効規則（支持されたときだけ置き換える）では C1 の 1 位が残った。悪化はしていない。
- graph support の順位ではこのケースだけ正しい候補が 1 位になった（評価用 26 件中 16 件、主指標は 15 件）。ただし事前指定の主指標ではない。この 1 件の差は、指標を変える根拠としては弱い。

### 1.3 支持されなかった（既存の結果は変えない）
- 8_6 系（隣接切片）：正しい候補（image#0）の主指標は 0.002〜0.013。最大でも誤った points の候補の 0.034〜0.040 だった。
  - 隣接切片では核は別の細胞なので、B2 がほとんど採択しないのは期待どおりである。
  - 主指標で順位をつけるだけで置き換えると、P8_6_IF500 では C1 の正しい 1 位を誤った候補に置き換えてしまう（**悪化**）。
  - 事前指定の支持条件（≥0.10）はこれを止めた。実効規則での悪化は 0 件。
- 負例（absent 3、N6_2 / N8_6 の HEexclude）では、どれも支持されなかった。誤った支持は 0 件。

## 2. Phase 1：誤った支持の危険（起きなかったが、近かった例）

### 2.1 周期的な組織（repeat=1、seed 1001）
| 候補 | 正しい領域 | B2 採択率 | decoy | 主指標 | B2 precision |
|---|---|---|---|---|---|
| points#2 | × | 0.642 | 0.004 | **0.638** | 0.0 |
| points#0 | × | 0.627 | 0.002 | 0.625 | 0.0 |
| points#3 | × | 0.625 | 0.000 | 0.625 | 0.0 |
| points#5 | × | 0.624 | 0.011 | 0.613 | 0.0 |

- repeat=1 では、Fixed の組織の中に、Moving と同じ核の配置がそのまま繰り返し現れる。誤った領域でも核の位置関係が一致するので、B2 は 6 割以上の核を matched にする。真の ID との一致（precision）は 0 である。
- mirror decoy は鏡像なので、**平行移動した繰り返し**は偶然の水準として差し引けない。主指標と比の条件は満たしてしまう。
- 今回は、繰り返しのコピーが 4 つ候補に入っていて差（0.013）が 0.05 に届かなかったので、「支持されない」になった。**コピーが 1 つだけ候補に入っていたら、誤った支持になっていた**。
- 結論：Graph/UOT/B2 の採択は「その姿勢で核の配置が局所的に整合する」ことを示すだけで、領域が正しいことは示さない。周期的な構造（腺管が並ぶ組織など）では、領域の正しさの独立した証拠にはならない。

### 2.2 6_2 の関係の矛盾
- P6_2 系では、正しい候補の主指標が 0.58〜0.61 で、強く支持された。
- 6_2 は切片関係の来歴が矛盾したまま（11-11）なので、この支持は「同じ細胞が見つかった」ことの証明として扱わない。核の配置が非常によく一致する、という事実だけを報告する。

## 3. Phase 2：局所変形の失敗と危険

### 3.1 誤った領域でも、既存の監査（common_audit）は局所変形を通す
誤った領域の候補で局所変形を試した場合に、適用まで進んだ件数：

| データ | B（既存 TPS） | B′（MNN＋RBF） | C（B2＋RBF） | D（UOT） | E |
|---|---|---|---|---|---|
| SYN-C1（C1 の 1 位が誤り、15 件） | 0 | 9 | 1 | 3 | 1 |
| REAL-D（誤った候補、27 件） | 0 | 23 | 0 | 16 | 0 |

- 既存の監査が見ているのは、変形場が滑らかで foldover がないことと、点の近さが悪化しないことだけである。**領域が正しいかどうかは見ていない**。最近傍でアンカーを作る B′ と、柔らかい対応を使う D は、誤った領域でも数百個のアンカーを作り、10 µm 程度の変位を適用してしまう。
- C / E は、誤った領域では B2 の matched がほとんど出ない。そのため、アンカーが 20 個未満になって止まる（REAL-D では 27 件中 0 件の適用）。SYN-C1 の 1 件は repeat=1 の周期的なケース（§2.1）で、そこでは核の配置が本当に一致している。
- 結論：局所変形は、領域が別の方法で検証された後にだけ実行するべきである。D / B′ を本番に入れる場合は、領域の検証（C3 など）を前提条件にする必要がある。

### 3.2 正しい領域でも、変形が小さいデータでは Affine を悪化させる（C / E）
SYN-C1 の C1 の 1 位が正しい 23 件について、アンカーに使わなかった共有核の TRE の中央値（µm）：

| 条件 | A | B′ | C | D | E |
|---|---|---|---|---|---|
| base（変形なし） | 0.95 | 1.47 | 1.31 | **0.80** | 1.29 |
| deform=5 | 3.39 | 5.03 | **1.47** | 2.14 | 1.87 |
| deform=10 | 5.87 | 12.31 | **3.02** | 3.86 | 3.76 |
| ratio=0.25 | 0.91 | 2.90 | 1.54 | **0.75** | 1.50 |

- Affine との勝ち／負け（差が ±0.1 µm を超えたもの）：D は 22 勝 0 敗、C は 6 勝 16 敗、B′ は 1 勝 17 敗。
- 変形がほとんどないデータでは、C は B2 の組の位置の揺らぎ（核の検出誤差）に合わせてしまい、アンカー以外の核をかえって約 0.3 µm 動かしてしまう。D は信頼度で変位を縮めるので、この悪化が起きない。
- 真の変形が大きいとき（deform=5、10、SYN-FIELD）は、C がいちばん良い。
- **実データでは「変形が大きいかどうか」が事前には分からない**ので、C を常に使うのは安全ではない。

### 3.3 既存の点のゲートが C を棄却する（SYN-RL、REAL-S）
- SYN-RL の 2 件（seed 4102、4101）：C は、変形場の誤差（試行時の EPE 1.15 µm と 0.46 µm）では最良だった。それでも、既存の `point_improvement_or_degradation_gate` で棄却された。
  - このゲートは、全ての核の最近傍距離の改善を見る。B2 の matched は核の一部にとどまり、それ以外の核の最近傍距離はほとんど変わらないので、「改善が不十分」と判定された。
- REAL-S（serial_section_pair）：B2 のアンカーは 26 個だけで、C は最近傍距離を改善しなかった（10.02→10.09 µm）。棄却は妥当である。D（10.02→8.63 µm、09-11 と一致）と B′ は適用された。最近傍距離の改善は、細胞同定の精度ではない。

### 3.4 実データの隣接切片（8_6）
- 正しい領域の候補（image#0）で、B′（414 アンカー）と D（570 アンカー）は監査を通って適用された。
  - ユーザーの独立ランドマーク 8 点の残差の中央値は、Affine の 21.53 µm に対して、B′ が 21.51 µm、D が 21.24 µm だった（`T_search` の姿勢では、Affine 20.98 µm、B′ 21.17 µm、D 21.08 µm）。**変わらないか、わずかに悪化した**。
  - 隣接切片の核は別の細胞なので、核どうしを寄せる局所変形が組織の対応を改善しないのは自然である。
- C / E は B2 の matched が 0〜6 個しかなく、適用されなかった。

### 3.5 UOT（D）の数値的な失敗：P6_2
- P6_2_orig などで、D は `invalid UOT plan: final_error=None` で失敗し、Affine に戻った。
- 原因（`dev/dbg_uot_6_2.py`）：translation-invariant な Sinkhorn が、ほぼ 0 の輸送量を返し、エラーの記録も空のまま終了している。
- 既存の `validation_lib.run_uot` を変更しない方針なので、修正はしていない。研究ラッパーの側で例外を受け止め、Affine に戻している。

## 4. まとめ（危険の一覧）
1. 候補に正解がない（候補生成の再現率）。並べ替えでは解決しない。
2. 周期的な組織での誤った支持。mirror decoy では検出できない。
3. 誤った領域への局所変形の適用。既存の監査は領域の正しさを見ない。
4. 変形が小さいときの過剰適合（C / E）。
5. 隣接切片では、核対応による支持も局所変形による改善も期待できない。
6. UOT の数値的な失敗（6_2）。今のラッパーは Affine に戻している。
