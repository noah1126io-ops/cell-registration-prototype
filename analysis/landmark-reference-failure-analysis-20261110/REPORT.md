# ランドマーク変換を基準にした 031-8_6 位置合わせ失敗の検証と修正（2026-11-10）

## 結論（要約）
- **8_6 の位置の推定そのものは、10/27 の時点で成功していた。**
  - 自動探索の結果（`occ+cleft`、image#0）は、ランドマーク変換から 19〜23 µm の位置にある。
  - これは、ランドマーク自体の精度（1点ずつ抜いた検証の誤差 LOO の中央値 23.7 µm）と同じ程度。
- **NOT_ACCEPTED（未採択）になった原因は、検証ルールが隣接切片に合っていなかったこと。**
  - HE は 031-7、IF は 031-8 の切片で、核は別の細胞。
  - 正解の位置の近くで最適化しても、3 µm 以内に核がある割合（≤3 µm 近接）は 0.074。間違った位置で同じ最適化をしたとき（中央値 0.076）と変わらない。
  - 採択基準の 0.25 には、原理的に届かない。
- **画面の表示も原因を隠していた。**
  - 失敗した段階として「C1（探索）」と表示されていたが、実際に止まっていたのは C3（検証）。
  - 段階を全探索の最小値で決めていたため、曖昧だった核探索（AMBIGUOUS）の C1 が、画像探索の C3 を上書きしていた。
- **修正**（registration_core 1.2）
  - 切片の関係（同一／隣接）を、ファイル名から判定する。
  - 隣接切片では、核の検証と核の ICP を合否に使わない。代わりに、独立した「象限一致チェック」を行う。
  - 合格した場合は `TISSUE_LEVEL`（組織レベルで位置決定）とする。`accepted` は False のままで、Workflow D には渡さない。
  - 失敗した段階は、主の探索（画像探索）の段階で表示するように直した。
- **結果**
  - 8_6 は NOT_ACCEPTED から **TISSUE_LEVEL** になった（4象限すべてが 10 µm 以内で一致）。
  - 6_2 は **ACCEPTED** のままで、変換は 10/22 と完全に同じ（差 0.0）。
  - 誤った候補 8 個とランダムな配置 17 個は、すべて不合格（一致したのは最大でも 1/4 象限）。

## 3. C3 で止まった理由：隣接切片では核が対応しない（`ceiling.py`）

正解の位置の近く（±24 µm、±3°、スケール 0.97〜1.03）で、≤3 µm 近接が最大になる位置を探した。比較のため、間違った位置 20 か所の近くでも同じ最大化をした（選び方の有利さをそろえた比較）。

| | 正解での値 | 正解の近くでの最大 | 間違った位置での最大（中央値 / 最大） | 採択基準 |
|---|---|---|---|---|
| 6_2（同一切片） | 0.774 | 0.774 | 0.066 / 0.096 | 0.25 |
| **8_6（隣接切片）** | 0.052 | **0.074** | **0.076 / 0.083** | 0.25 |

- 8_6 では、核の近接は正解と不正解を全く区別しない。
- 画像の核マップの相関（`imgnull.py`）でも同じ結果。正解での `nuclear_corr` は 0.005 で、ランダムな配置 273 個と比べた z は 0.6。
- **結論：2026-10-19 に決めた核ルールは同一切片を前提にしている。隣接切片では、位置が正しくても合格できない。**

## 4. 隣接切片で使える独立した証拠（`imgnull.py`、`quadrants.py`）

**画像の指標ごとの比較（`imgnull.py`）**
- 8_6 では IF 視野がすべて組織の中にある。そのため、組織の輪郭（`edt`、envelope chamfer）からは情報が得られない。
- 探索と独立な `tissue_corr` は、正解 0.167 に対して、誤った候補の最大が 0.206。区別できない。
- 正解と誤りを分けられるのは、探索に使った特徴（occ/cleft）だけ。cleft の相関は image#0 が 0.248、誤った候補の最大が 0.173。
- 探索に使った特徴をそのまま検証に使うのは独立な検証にならないので、単純な相関の閾値は採用しなかった。

**象限一致チェック（`quadrants.py`）**
- IF 視野を 2×2 に分け、各象限の組織だけを使って、候補の周辺で位置を探し直す。
- 正しい領域なら、4つの象限がそれぞれ独立に同じ位置を再現するはず。全体スコアの偶然の極大なら、象限ごとには再現しない。
- 合格の条件は、結果を見る前に `PRESPECIFIED_RULE.md` に書いた（3/4 象限以上、30 µm 以内かつ 2° 以内）。

| sample | 姿勢 | ランドマーク・参照との差 | 一致した象限 | 判定 |
|---|---|---|---|---|
| 6_2 | 参照（採択済み） | 0 | 4/4（4〜7 µm） | 合格 |
| 6_2 | image#0 | 2 µm | 4/4（4〜10 µm） | 合格 |
| 6_2 | image#1〜3（誤り） | 111〜1004 µm | 0〜1 | 不合格 |
| 6_2 | ランダム 9 個 | — | 0 | 不合格 |
| 8_6 | **image#0** | 23 µm | **4/4（3〜10 µm、±1°）** | **合格** |
| 8_6 | image#1〜5（誤り） | 1005〜1289 µm | 0〜1 | 不合格 |
| 8_6 | ランダム 8 個 | — | 0 | 不合格 |
| 8_6 | ランドマーク変換そのもの | 0 | 2/4（7、20、40、32 µm） | 不合格 |

- ランドマーク変換そのものは 2/4 で不合格だった。全象限が、相対スケール 1.03 倍（上限）の位置を選んでいる。
- これは、ランドマークのスケール（0.946）が、画像から求まる最適値（≈0.99〜1.0）より小さいことを示している。ランドマークの精度の範囲内の偏りだが、次にランドマークを追加するときの注意点になる。

## 7. 限界と注意
- **サンプル数が少ない。** 画像がある実データは 2 サンプルだけで、隣接切片は 8_6 の 1 例しかない。
  - 誤った候補 8 個とランダムな配置 17 個はすべて不合格だったが、偽陽性の率を推定できる規模ではない。
  - `serial_section_pair_20260904` は核の座標しかなく画像がないので、検証に使えなかった。
- **8_6 は独立な検証データではない。**
  - `occ`/`cleft`（10/27）は 8_6 を見ながら作った特徴量。
  - ランドマークを登録したのも、自動探索の結果を見た後。
  - 一方、象限チェックの条件は結果を見る前に決めた。また、同一切片の 6_2 でも同じように誤りを弾いた。
- **`TISSUE_LEVEL` の精度は組織レベル（約 20〜30 µm）まで。** 細胞同士の対応付け（Workflow D）には使えない。
- **切片の関係の判定はファイル名の規則に頼っている。** 規則に合わないファイル名は「不明」になり、同一切片として扱われる（従来と同じ動作）。
- **計算した場所について。** ceiling.py、imgnull.py、quadrants.py はゲートウェイホスト（mib-public-gw01）で実行してしまった。エンジンの実行と pytest は Slurm で実行した。
