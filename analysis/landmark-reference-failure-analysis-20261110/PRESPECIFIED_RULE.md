# 隣接切片ペアの検証ルール（2026-11-10 事前指定）

このファイルは、`quadrants.py` で誤り候補・ランダム配置の結果を見る**前に**書いた。
ここで決めた値は、結果を見た後に変えない。変える場合は新しい日付で別のルールとして記録する。

## 適用範囲
- 対象は、HE と IF が**隣接切片**のペアだけ（例：031-8_6 は HE 031-7 と IF 031-8）。
- 同一切片のペア（例：031-6_2）は、従来の核ルール（2026-10-19）のまま変えない。

## 隣接切片ペアの判定（C3）
1. 核配置のチェック（≤3 µm 近接 ≥ 0.25、かつ mirror null の 3 倍以上）は、計算して記録するが、合否には**使わない**。
   - 理由：隣接切片では核が別の細胞なので、正しい位置でも偶然一致の水準を超えない（`ceiling.json` で確認）。
2. 画像探索の verdict が UNIQUE であること。
3. 象限一致チェック：IF 視野を 2×2 に分け、各象限だけで局所画像探索をやり直す。
   - 局所探索の範囲：±4°（1° 刻み）、スケール 0.97/1.00/1.03、並進 ±100 µm。特徴は occ+cleft。
   - 各象限の最適位置と候補の位置の差を、象限の中心で測る。
   - 4象限のうち **3つ以上**で、位置の差が **30 µm 以下** かつ回転の差が **2° 以下**なら合格。
4. 2 と 3 を満たした場合、判定は `TISSUE_LEVEL`（組織レベルで位置決定）とする。
   - `accepted` は False のまま（細胞レベルの採択ではない）。
   - Workflow D への受け渡しはしない（ACCEPTED_STATUSES は変更しない）。
   - 精度の目安は、ランドマークで測れる精度（LOO 中央値 約 24 µm）程度として記録する。

## 精密化（C2）
- 隣接切片では、核の ICP（cropped_icp）の結果を最終変換に使わない。最終変換は探索で求めた位置のままにする。
- ICP は診断用に実行して、その移動量だけを記録する。
- 理由：対応しない核に合わせても意味がない。実際、8_6 で ICP は 12.7 µm 動いたが、ランドマーク誤差は 21 µm → 22 µm でほとんど変わらなかった。

## 30 µm の根拠
- 8_6 のランドマーク変換の LOO 誤差（中央値 23.7 µm）と同じ程度の値にした。
- 探索で候補を区別する距離 distinct_um = 40 µm より小さい。
