# E0x：構成要素のablationとSynthetic難易度実験（Phase 1、2026-10-20〜22）

- 前提：2026-10-19の `optional-image-assisted-registration-20261019`。そこで導入したE0x（視野の大きさの違いに対応するPoint-only探索）を対象にします。
- プロトコル：`protocol.md`（評価の前に固定）。結果を見た後の変更と追加は、同じファイルの「変更履歴」に記録しています。
- 計算：Slurm `mib-dbia`（CPU）。実データのablationは16件、合成データは132 case・177 runです。
- 実データの031-6_2と031-8_6は、開発中にも見ています。独立したテストではなく、記述的な結果として扱います（`sample_provenance.md`）。031-6_2は2026-10-20の訂正により**別の切片同士**として扱います。
- UIについては別の報告書 `UI_IMPLEMENTATION_REPORT.md` と `ui_test_results.md` にあります。

## 0. 要約

1. **誤った採択（false accept）は、177 runのすべてで0件でした。** 正しい領域が存在しない陰性対照（absent）も3/3が不採択（AMBIGUOUS）です。
2. **E0xで効いている構成要素は、ICPの視野を重なり部分に限ることです。** 実データ（031-6_2、IF Fixed）でも合成データ（overlap 0.5）でも、ICPの視野を限らない場合はICPが誤った位置へずれて失敗します。canvasの拡張は採択の余裕（margin）を広げますが、成否は変えませんでした。
3. **E0xは次の条件に強い結果でした：** 視野の大きさの比（0.25〜1）、回転（0〜180°）、scale（0.9〜1.1）、位置のずれ、核の密度（500〜4000 /mm²）、非共有の核70%まで、検出漏れ40%まで。これらはすべて3/3で正しく採択されました。
4. **E0xが失敗した条件は次のとおりです。**
   - **繰り返し構造**：r=0.5で1/3、r≥0.8で0/3。いずれもAMBIGUOUSとして不採択になり、誤った採択はありません。
   - **重なり30%**：0/3。
   - **非共有の核85%**：位置合わせ自体は成功しても、採択の基準を満たしません。
   - **局所変形が大きい場合**：RMS 10 µmで0/3。
5. **採択の基準（≤3 µm ≥ 0.25）には構造上の限界があります。** 共有される核が少ない（非共有85%）と、正しい変換でも≤3 µmの割合が0.10〜0.17にしかなりません。そのため、5件の正しい位置合わせ（誤差0.6〜2.5 µm、偶然一致の6〜12倍）が不採択になりました。安全側に倒れる設計なので基準は変えていませんが、限界として記録します。
6. **031-8_6は、どの候補にも「共有された核の配置」が見当たりません。** 実データで測れる量で合成条件と対応づけると、陰性対照（absent）に最も近い結果でした（§3）。繰り返し構造の指標は合成のbase以下で、繰り返し構造では説明できません。H&Eが031-7の切片であること（切片間の距離はUNKNOWN）と矛盾しません。ただし、この結果だけでは「対応する領域がない」とは断定できません。

## 1. 実データのablation（`e0x_ablation.csv`、`e0x_ablation.png`）

各要素の意味は次のとおりです。canvasは、探索するcanvasの範囲です（bbox＝Fixedの範囲、union＝両側の範囲を合わせたもの）。ICPは、ICPで使う点の範囲です（all＝全体、crop＝重なり部分のみ）。X3がE0xにあたります。

| sample | Fixed | X0 (bbox / all) | X1 (union / all) | X2 (bbox / crop) | X3 = E0x (union / crop) |
|---|---|---|---|---|---|
| 031-6_2 | HE | **採択** 0.599（null 0.049） | **採択** 0.599 | **採択** 0.599 | **採択** 0.599 |
| 031-6_2 | IF | FAIL（核の幾何）0.065、NN 32.8 µm | FAIL 0.065 | **採択** 0.599（margin 0.27） | **採択** 0.599（margin 0.48） |
| 031-8_6 | HE | AMBIGUOUS 0.015 | AMBIGUOUS 0.014 | AMBIGUOUS 0.030 | AMBIGUOUS 0.041（null 0.031） |
| 031-8_6 | IF | LOW_PEAK 0.162（null 0.140） | AMBIGUOUS 0.372（**null 0.372**） | LOW_PEAK 0.028 | AMBIGUOUS 0.041（null 0.029） |

数値はIF frameでの≤3 µm近接率です。

- 031-6_2では、小さい側（IF）をFixedにしたときに、ICPの視野を限るかどうか（X0/X1とX2/X3の違い）で結果が分かれます。探索の段階では同じ正しい領域を見つけています。しかし視野を限らないICPは、重なっていない部分の核に引っ張られて32 µmずれました。
- 031-8_6のIF Fixed・X1では≤3 µmが0.372と高くなりました。ただし鏡像のnullも0.372で、偶然の一致と区別できません。ICPの視野を限らないと点が密集した配置に引き込まれることがあり、nullとの比較が必要であることを示す例です。
- 031-8_6の候補（`candidate_region_diagnostics.csv`、`candidate_regions_031-8_6.png`）：上位6候補はどちらの方向でも、≤3 µmが0.03〜0.06、nullとの比が1.0〜2.1でした。幾何学的な整合を満たす候補は1つもありません。候補どうしは互いに410〜1980 µm離れており、z scoreの差もわずかです（top 6.84に対し2位 6.63）。

## 2. Synthetic難易度実験（`difficulty_sweep.csv`、`difficulty_sweep_summary.csv`、`difficulty_sweep.png`）

基準条件は、ratio 0.5、overlap 1.0、非共有0.3、検出漏れ0.1、回転30°、位置のずれ0.2、scale 1.0、密度2000、変形0、繰り返し0です。各条件はseed 3件で、数値は正しく採択された割合です。

### 2.2 視野の大きさの比 × 非共有（`difficulty_fov_vs_nonshared.png`）

| ratio \ 非共有 | 0 | 0.5 | 0.85 |
|---|---|---|---|
| 0.25 | 3/3 | 3/3 | 0/3（領域も見つからず、AMBIGUOUS） |
| 0.5 | 3/3 | 3/3 | 0/3（位置合わせは2/3成功、基準未満で不採択） |
| 1.0 | 3/3 | 3/3 | 0/3（位置合わせは3/3成功、基準未満で不採択） |

視野が小さく、かつ共有される核が少ないと、探索の段階で領域を見つけられなくなります。視野が大きい場合は、採択の基準だけが問題になります。

### 2.3 安全性についての所見

- **誤った採択は0件です。** 177 runのうち、UNIQUEが157件、AMBIGUOUSが20件でした。
- **繰り返し構造には一意性の判定（UNIQUE）が必要です。** repeat=1・seed 1001では、周期の4倍（約1280 µm）ずれた位置で≤3 µmが0.616、nullとの比が26でした。幾何学的な整合だけなら採択されてしまう解です。これを止めたのは、AMBIGUOUS（margin 0.007）の判定でした。
- **安全側に倒れて不採択になったもの（誤差3 µm以下なのに不採択）** は8 runです。
  - 非共有0.85で7 run。
  - repeat=0.5で1 run（margin 0.069でAMBIGUOUS）。
  - 「非共有0.85」と「格子 ratio 0.5・非共有0.85」は同じ条件なので、7 runのうち2 runは重複しています。重複を除くと、非共有0.85は5 run、全体では6 runです。
- 境界に近い例として、次の2つもありました。
  - 検出漏れ0.6・seed 1003：誤差3.3 µmで不採択。
  - 局所変形5 µm・seed 1002：誤差3.5 µmで採択（20 µm以下なので、false acceptには当たりません）。
- **実行時間**：X3_Lは中央値約400 s、ratio=1では約550〜600 sでした。X0_Lは約200 s、X3_Sは約550〜610 sでした（4コア）。

## 3. 031-8_6と合成条件の対応づけ（記述的）

プロトコル§5に従い、実データから測れる量だけで対応づけます。

| 量 | 031-6_2 | 031-8_6 | 合成データで近い条件 |
|---|---|---|---|
| 視野の面積比（IF/HE） | 0.23 | 0.23 | ratio 約0.48（＝基準の0.5） |
| 組織envelopeの比（IF/HE） | 0.54 | 0.22 | — |
| 核密度（/mm² 組織envelope、HE / IF） | 1544 / 2521 | 1188 / 1737 | 密度1000〜2000（3/3で成功する範囲） |
| self-similarity指標（HE / IF） | 0.38 / 0.33 | **0.10 / 0.05** | base 0.11 / 0.11、r=0.5 0.20 / 0.16、r=0.8 0.53 / 0.28（`structure_mapping.csv`） |
| 最上位候補の≤3 µm（nullとの比） | 0.60（12〜13倍） | **0.04〜0.06（1.4〜2.1倍）** | absent：0.02〜0.04（1.4〜9倍）、ratio 0.25・非共有0.85：0.05〜0.24（1.0〜1.3倍）。非共有0.85（ratio 0.5）は正しい位置で0.10〜0.16（6〜12倍） |

- 031-8_6の繰り返し構造の指標は、合成データのbase（繰り返しなし）以下です。**繰り返し構造は、031-8_6の失敗の主な原因ではないと考えられます。**ただし、この指標は組織の形にも影響されます。031-6_2は指標が高くても成功しているので、指標の絶対値だけで難しさを判断することはできません。
- 視野の比、密度、回転、scaleについては、合成データで3/3成功している範囲にあります。
- 031-8_6で観察された信号の強さ（偶然一致の約2倍以下）は、**absent（正しい領域がない）や、視野が小さく非共有の核が85%の条件**と同程度でした。非共有85%でも視野が十分あれば、正しい位置では偶然の6倍以上の一致が見えていました。031-8_6はそれよりも弱い結果です。
- 解釈：031-8_6のH&Eは031-7の切片で、切片間の距離はUNKNOWNです。両側に共有される核の配置が、点群で検出できるほどには残っていない可能性があります。考えられるのは、切片が離れている場合と、蛍光の視野に対応する部分がH&E視野に含まれない場合のどちらかです。この2つを点群だけで区別することはできません。

## 4. 結論と次の手

- **E0xの採用（10-19の結論A）は、Phase 1の結果からも支持されます。** 主要な構成要素はICPの視野の限定です。canvasの拡張は余裕を広げるために残します。
- **採択の基準は変えません。** 誤った採択は0件でした。正しいのに不採択になるのは、共有される核が非常に少ない場合（約15%）と、繰り返し構造の場合に限られます。
- **031-8_6はunresolvedのままとします（10-19の結論Fを維持）。** 点群側の手法をさらに調整しても、解決する見込みは低いと判断します。進めるには、次のいずれかの追加情報が必要です。
  1. 031-8自身のH&E（同じ切片か、隣の切片）
  2. 031-7と031-8の切片間距離
  3. 蛍光視野がH&E上のどのあたりにあるかの粗い注釈
- **残る課題**：
  - 採択の基準の限界（共有される核が少ない場合）を補う手段。例：局所的な一致の連結性や、nullとの比を主な基準にする案。導入するには、独立したデータでの事前登録と検証が必要です。
  - 局所変形が大きい場合（RMS 10 µm）の扱い。similarityの上に非剛体の段階を足すかどうかです。
