# 事前固定プロトコル：E0x Synthetic難易度実験（2026-10-20、実行前に記録）

このファイルは評価ジョブを投入する前に書きました。結果を見てから変更した箇所は、末尾の「変更履歴」に記録します。

## 1. 生成器（`synth.py`、点群のみ）

実データの031-8_6に合わせ込まないため、点群だけの合成データを使います。パラメータは一般的な値で決め、031-8_6の値に合わせて調整していません。

- **組織**：Fixed視野（2100 µmの正方形）の周囲も含む領域に、相関長60 µmの滑らかな乱数場を作ります。上位50%を組織とします。
  - 繰り返し構造 r：乱数場 =(1−r)×一様な乱数場 + r×（320 µmのpatchを敷き詰めた周期場）
- **核**：組織内にPoisson過程で配置し、4.5 µmのhard-coreで間引きます。密度は組織1 mm²あたりの核数です。
- **Moving**：大きさ ratio×2100 µm の正方形視野で、既知のsimilarity変換を持ちます。
  - fixed_world = s·R(θ)·moving_world + t
- **Movingの核**（Fixed側も同じ規則）：
  - 検出漏れ m：各側で独立に、割合mの核を除きます。
  - 非共有 ns：Movingの核のうち割合nsを、同じ組織mask内の別の核過程（別の切片の細胞に相当）に置き換えます。
  - 局所変形：相関長150 µm、RMS振幅aの滑らかな変位場を加えます。
  - 位置のばらつき：0.8 µm。
- **撮像範囲の不一致と非共有を分けて扱います。**
  - 撮像範囲の不一致は、ratio（視野の大きさの比）とoverlap（Moving視野のうちFixed視野に入る割合）で表します。
  - 非共有は、ns（同じ場所でも細胞が違う割合）で表します。
- **陰性対照（absent）**：Movingを独立な別の組織から作ります。正しい領域は存在しません。

## 2. 条件

| 要因 | 水準（太字が基準） |
|---|---|
| ratio（Moving / Fixedの視野の大きさ） | 0.25、**0.5**、0.75、1.0 |
| overlap（目標値。実際の値を記録） | **1.0**、0.75、0.5、0.3 |
| 非共有 ns | 0、**0.3**、0.5、0.7、0.85 |
| 検出漏れ m | 0、**0.1**、0.2、0.4、0.6 |
| 回転 θ | 0、**30**、45、90、180 ° |
| 位置（Fixed中心からのずれ / 2100 µm） | 0、**0.2**、0.4 |
| scale s | 0.9、0.95、**1.0**、1.05、1.1 |
| 密度（/mm²組織） | 500、1000、**2000**、4000 |
| 局所変形 RMS | **0**、2、5、10 µm |
| 繰り返し r | **0**、0.5、0.8、1.0 |
| absent | 1条件 |
| ratio × ns の格子 | ratio {0.25, 0.5, 1.0} × ns {0, 0.5, 0.85} |

- 1要因ずつ、基準から変えます（OFAT）。格子だけは2要因を同時に変えます。
- **seed**：評価用は1001、1002、1003（各条件3件）です。開発用はseed 0で、生成器と実行経路の確認だけに使い、結果には含めません。

## 3. 手法

- **X3_L**：E0x。視野の大きい側をFixedにします。全条件で実行します。
- **X0_L**：canvasを拡張しない、ICPの視野も限定しない。大きい側をFixedにします。ratio・overlap・scaleの各要因で実行します。
- **X3_S**：E0x。視野の小さい側をFixedにします。ratioの要因で実行します。

探索設定は2026-10-19のE0xと同じで、変更しません（回転4°、scale 0.95〜1.05、fine ±3%、canvas 8 / 4 µm）。

## 4. 評価基準（事前固定）

- **誤差**：Moving視野内（Fixed視野と重なる部分）の11×11の格子点で、推定変換と真の変換の距離を測り、その中央値とします。
- **region_found**：探索pose（ICP前）の誤差が20 µm以下。
- **reg_success**：最終変換の誤差が3 µm以下。
- **accepted**：verdictがUNIQUE、かつ幾何学的整合（≤3 µm ≥ 0.25 かつ null比 ≥ 3）を満たす。基準は既存と同じです。
- **correct_accept**：accepted かつ reg_success。
- **false_accept**：accepted かつ誤差 > 20 µm。absentでは、acceptedはすべてfalse acceptです。
- **true_id**：共有核のうち、変換後の最近傍が真の相手で、かつ3 µm以内にあるものの割合。生物学的な同一性は合成データでしか定義できないので、この指標は合成データに限ります。

## 5. 実データとの関係

- 031-6_2と031-8_6は、設定を調整する際にも見たデータです。最終的な独立テストとしては扱わず、記述的な結果として報告します。
- 合成データの条件のうち、どれが031-8_6に近いかは、実データから測れる量（視野の比、overlapの推定、核密度、非共有の推定）だけで対応づけます。
