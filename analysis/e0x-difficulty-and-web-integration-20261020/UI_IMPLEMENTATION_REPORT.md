## 3. 主な機能

- **Before / After**：同じFixed frameで切り替えます。Beforeは「変換なし。原点はUNKNOWN」と表示します。
- **画像の重ね合わせ**：H&E、蛍光、重ね合わせ、Fixedのみ、Movingのみ、チェッカーボード。透明度とチェッカー幅のスライダー、ホイールでのZoom、ドラッグでのPanがあります。表示用の画素値も選べます（H&E：RGB／核強調、蛍光：表示用RGB／核推定B−R）。
- **核点群**：H&E核と蛍光核の表示をそれぞれON/OFFでき、マーカーの大きさも変えられます。推定対応（mutual NN ≤10 µm）の残留変位ベクトルを、≤3 / ≤5 / >5 µmで色分けします。「同一細胞の証明ではありません」と常に表示します。
- **領域**：両側のImage FOV、核検出範囲（convex hull）、組織領域（2026-10-19の組織mapの輪郭）、候補ごとの対応領域、選択中の対応領域。
- **ROI詳細**：中心とサイズを指定すると、その範囲だけを高解像度（0.2〜0.8 µm/px）でタイルから読んで重ねます。
- **Candidate Viewer**：候補ID、領域（並進）、回転、scale、z score、NCC、topとの差（gap）、≤3 µm、null、ICPによる移動量、重なり面積、Safety（PREVIEW ONLY）。選んだ候補は、探索pose（ICP前）またはICP後としてプレビューできます。
- **Safety表示**：UNIQUE / Accepted、AMBIGUOUS、LOW_PEAK、FAIL、IMAGE_UNUSABLE、POINT_ONLY_FALLBACK、UNVERIFIED。採択されていない結果と候補には、常に「PREVIEW ONLY — Workflow Dへ渡しません」と表示します。閾値を変える入力欄はありません。
- **方式比較**：Method、Safety、NN median、≤3 µm、null、回転、scale、並進（HE→IF）、tissue Dice、核mapの相関、実行時間、fallbackと理由。探索に使った画像特徴量には†を付け、独立な根拠ではないことを示します。Fixed/Movingを交換したときの一貫性の表も付けました。
- **Warp Preview**：保存済みの変換で、Moving画像を**逆写像**でFixed frameのgridにresamplingします。補間（bilinear／nearest）・範囲外の扱い・source level・使った順写像を記録して表示します。無効領域はalphaを0にしたPNGでダウンロードでき、Accepted以外は名前に `_PREVIEW_ONLY` を付けます。元の画像は変更しません。
- **新規実行**：入力検証、結果のキャッシュ（同じ設定の完了済み結果があれば再投入しない）、同じ設定の重複投入の防止、同時2件までの上限、投入前の確認、10秒ごとの状態更新（ページは止まらない）、ログの表示、自分のジョブだけのキャンセル。

## 4. 確認中に見つけて直した不具合

| 不具合 | 発見 | 修正 |
|---|---|---|
| Warp Previewで変換が常に逆向きに使われていた（`oriented()` に記録オブジェクトを渡していた）。画像と点が同じように間違うため、重ね合わせだけでは整合して見えた | スクリーンショットで、蛍光画像がH&E組織からずれた位置に出ていた | 呼び出しを修正。`oriented()` に型チェックを追加。E2Eに「使った変換が保存値と一致する」確認を追加 |
| 指標が空の結果（Point-onlyペア）で表がKeyErrorになる | 本番ログ | 空のときは「記録なし」と表示 |
| タブの中のviewerが幅0で初期化され、何も描かれない | スクリーンショット | ResizeObserverで、表示されたときにfitし直す |
| 単位がpxのframe（spacing UNKNOWN）でスケールバーが「µm」と表示される | スクリーンショット | frameごとの単位をmanifestに明記し、単位が違えば注記 |
| 送信後に確認チェックが残り、二重投入しやすい | E2E | 投入するたびに確認をリセット。同じ設定のジョブが待機中・実行中なら投入できない |
| Fixedを切り替えても、結果の選択が前の方向のまま残る | E2E | 結果選択のkeyにsampleと方向を含める |

## 6. 追加：手動調整（2026-10-22）

ユーザーの依頼により、表示中の変換に回転・拡大縮小・平行移動を追加できるようにしました。

- **場所**：Viewerタブの「手動調整（回転・拡大縮小・平行移動）」。「手動調整を有効にする」をONにすると使えます。
- **基準**：その時点で表示している変換が基準になります。最終変換、候補（探索pose／ICP後）、Before（変換なし）のどれでも使えます。
- **入力**
  - 回転 Δθ（°、画面上で時計回りが正）
  - 拡大縮小 ×s
  - 平行移動 Δx・Δy（Fixed frameの単位）
  - 刻み：粗（5° / 0.05 / 50）、標準（1° / 0.01 / 10）、細（0.1° / 0.001 / 1）
  - 回転・拡大縮小の中心：Moving視野の中心（既定）、Fixed視野の中心、座標指定
- **式**：`p_fixed = s·R(Δθ)·(M_base·p + t_base − 中心) + 中心 + (Δx, Δy)`（`src/registration_explorer/manual.py`）
- **確認**：調整するたびに、画像と核点群、および「UI再計算の診断」（NN、≤3 µm、鏡像null）が更新されます。調整中はZoom/Panの位置が保たれます。保存済み指標は基準の変換の値であることを注記しています。
- **Warp Preview**：「Viewerで手動調整中の変換（未検証）を使う」で、手動変換による逆写像の画像を確認・ダウンロードできます（ファイル名に `_PREVIEW_ONLY`）。
- **保存**：名前とメモを付けて `runs/registration-explorer-manual/<sample>/<日時>-<名前>.json` に保存します。既存のファイルは上書きしません。基準（結果ID、候補、段階、変換）、調整量、中心、調整後の変換、UI診断、作成者、日時を記録します。保存せずにJSONをダウンロードすることもできます。保存した変換は、『Registration方式』の **Manual adjustment** から再表示できます。
- **安全性**：手動変換は常に **MANUAL (UNVERIFIED)**、`accepted=false` です。採択規則による判定を経ていないため、PREVIEW ONLYとして扱い、Workflow Dへは渡しません（受け渡しの経路はありません）。研究artifactや保存済み結果は変更しません。
- **テスト**：単体テスト2件（中心まわりの合成・恒等・不正なscale、保存と読み込み・上書きしないこと・壊れたファイルの除外）。ブラウザE2EのTest I 10項目（`ui_test_results.md`）。
