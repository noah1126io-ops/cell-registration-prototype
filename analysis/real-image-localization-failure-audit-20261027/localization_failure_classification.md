## 段階ごとの結論

- **C1（対応領域の探索）：** 従来は失敗していました（特徴量の問題）。修正後は、正しい領域が UNIQUE（margin 0.303）で1位になります。
- **C2（精密化）：** 崩れません。ただし、隣接切片では核ICPに情報がないため、精密化はほとんど何もしていません（探索poseのまま）。
- **C3（検証）：** 核の近接率による採択規則（変更していません）は満たされないため、NOT_ACCEPTEDです。安全側の正しい停止です。031-8_6の誤った変換は採択していません。
- エンジンが記録する `failure_stage` は、全探索のうち最も早い段階を返します。このため、核探索がAMBIGUOUSであることにより「C1」と表示されます。探索ごとに見ると、画像探索は search_ok = True、geometry_ok = False で、実際に止まっているのはC3です。判定規則は変えず、この点は報告にとどめます（`REPORT.md` §今後）。
