## 1. 人が見ている構造は特徴量に残っているか

| マップ | HE（031-8_6） | IF（031-8_6） | 人が見ている間隙の網目 |
|---|---|---|---|
| `tissue`（従来） | 光学密度。間隙が暗い線としてはっきり見える | **max(R,G,B)：Hoechstの核が明るい粒として支配的**。間隙は弱く見える程度 | HE：残る / IF：核の粒に埋もれる |
| `nuclear`（従来） | ヘマトキシリンの粒 | B−Rの粒 | 残らない（核の配置だけ） |
| `edt`（従来、探索では未使用） | 視野全体がほぼ一定 | 間隙の位置に偽の穴ができる | 残らない |
| `tissue_bin`（Otsu） | 組織と間隙を分けている | **核・膜と細胞質を分けている（組織率 0.40）** | IFでは誤り |
| `occ`（追加） | 光学密度を、組織の中央値で飽和させたもの | **max(G,R)（Hoechstを除く）** を同じ規則で飽和させたもの | 両方に残る |
| `cleft`（追加） | 1−occの帯域通過（60 µm） | 同左 | 両方に網目として残る |

画像品質の区別（`image_status` が判定しているのは2番目までです）：

1. ファイルとして読める：4画像とも読める。
2. 有効な組織情報を抽出できる：組織率と、自分の核とのAUCで判定。4画像ともusable。
3. **もう一方と比べられる構造を抽出できる**：従来の `tissue` は、031-8_6のIFでは**比べられない**（核のテクスチャになっている）。従来の判定では、これを検出できなかった。
4. その構造が対応領域の探索に役立つ：下の比較実験で評価した。

## 2. 比較実験（エンジンと同じ探索、粗探索の段階）

`landscape.py`：回転 0〜360°（4°刻み）× 倍率 0.90〜1.20、キャンバス 8 µm。

`rank_analysis.py`：エンジンと同じ規則（40 µm以内は同じ候補）で、異なる候補に並べたときの参照領域の順位を求めた。

結果：`candidate_rank_reference.csv`（v1）、`candidate_rank_v2.csv`（正規化を直した後）。

| 特徴量 | 031-8_6：1位の参照からの距離 / 参照領域の順位 / margin | 031-6_2：同左 |
|---|---|---|
| tissue+nuclear（従来の既定） | 1238 µm（θ=192°）/ **261位** / 0.04 | 7 µm / 1位 / 0.39 |
| tissue | 1225 µm / 21位 / 0.07 | 7 µm / 1位 / 0.08 |
| nuclear | 1548 µm / 圏外 / 0.06 | 7 µm / 1位 / 0.51 |
| points（核点群） | 1249 µm / 圏外 / 0.04 | 7 µm / 1位 / 0.43 |
| edt | 731 µm / 圏外 | 1271 µm / 圏外 |
| occ | 67 µm / 1位 / 0.18 | 7 µm / 1位 / 0.02 |
| cleft | 67 µm / 1位 / 0.35 | 7 µm / 1位 / 0.48 |
| **occ+cleft** | **67 µm / 1位 / 0.31** | **7 µm / 1位 / 0.37** |
| occ+cleft+nuclear | 57 µm / 1位 / 0.19 | 7 µm / 1位 / 0.44 |

（倍率を0.95〜1.05に限った値。0.90〜1.20に広げても、1位と参照領域の順位は変わらない。）

- 031-8_6の「参照からの距離 57〜67 µm」は、自動の最適値（θ≈12°、s≈1.00）と、手動参照（θ=15.6°、s=1.10）の差です。手動参照の倍率は、画像構造から見ると過大と考えられます（`localization_failure_classification.md` §C）。
- **核の配置を表す特徴量**（nuclear、points、従来のIF tissue）は、同じ切片の031-6_2では強く働きます。隣接切片の031-8_6では、正しい領域を候補に残せません。
- **組織構造の特徴量**（occ+cleft）は、両方のサンプルで正しい領域を1位にし、margin 0.31 / 0.37 で一意になります。

## 3. 正規化の不具合（開発中に見つけて修正）

最初の `occ` は「視野全体の中央値」で飽和させていました。031-6_2は組織が視野の18%しかないため、中央値が背景になり、スライドの縞模様まで組織として扱われていました（v1：cleftの1位が1275 µm離れる）。

基準を「Otsuより上（組織側）の中央値」に変えて解消しました。同じ規則をすべてのサンプルに使い、サンプルごとの閾値はありません。

ただし、この修正は031-6_2の結果を見て行ったため、**031-6_2も完全に独立した検証データではありません**（`REPORT.md` §過適合）。
