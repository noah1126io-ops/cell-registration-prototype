# 参照ランドマーク・参照変換の記録手順 — 2026-10-27

参照変換は、研究者が指定する**暫定**の変換です。Ground Truthではありません。

- 研究ストアには `MANUAL_UNVERIFIED` として保存し、採択されることはありません。
- 使い道は、自動探索の診断だけです（参照領域が探索されているか、何位か、各候補が参照からどれだけ離れているか）。

## 2. Explorerで対応点を記録する手順

1. 『Viewer（重ね合わせ・手動調整）』で、手動調整した変換（または参照に近い候補）を表示します。
2. ビューア左の『クリック操作』で対応点モードにし、HE上の構造（血管・腺管・腔・境界・間隙の分岐など）と、それに対応する蛍光側の同じ構造を順にクリックします。
3. 下の表で、各点の **種類**（vessel / duct / lumen / boundary / cleft / other）と **確信度**（high / medium / low）を選びます。
4. 『保存して参照変換に指定』を押します。保存されるものは次のとおりです。
   - 注釈（`landmarks`）：Sample ID、Fixed / Moving、landmark ID（L1…）、種類、確信度
   - 両画像の画素座標と frame座標（µm）
   - 物理原点：「frame-local。共通の原点はUNKNOWN」
   - 画像のfingerprint：パス、サイズ、mtime、先頭1 MiBのSHA-256
   - 作成日時、作成者（ストアが自動で記録）
   - 変換（`landmark`、`MANUAL_UNVERIFIED`）と、参照指定の注釈（`note`、role = reference_transform）
5. 推定は Umeyama相似変換＋反復的な外れ値除外です（`registration_core.reference.fit_reference`）。残差が `max(3 × 1.4826 × MAD + 中央値, 15 µm)` を超える組は除外し、最低3組は残します。
   - 3組以上：leave-one-out誤差を出します。
   - 6組以上：3組に1組を検証用に残し、held-out誤差を出します。
6. 『対応領域の探索』タブの『参照変換』欄で、すでにある手動変換を参照に指定することもできます。地図とViewerには、参照の領域が黄緑の破線で表示されます。
7. 同じ欄に、選んだ結果のすべての候補（探索pose / ICP後）と参照との比較表が出ます。
   - 列：参照からの距離（プローブ5点の中央値）、回転差、倍率比、対応点誤差

推奨：8組以上（held-out誤差を出すため）。種類が偏らないようにし、視野の四隅と中央に散らしてください。

## 3. 安全性

- 参照を指定しても、自動推定の結果・採択判定・保存済みのartifactは変わりません（追記のみ。新しい `note` 注釈が増えるだけです）。
- 参照変換を初期値にした探索（『新規実行』→ 注釈を使った探索）は `ASSISTED_REVIEW_REQUIRED` になり、自動採択されません。
- 完全自動の評価と、参照を使った実験は別に記録します（ストアの `mode` / `constraints`）。
