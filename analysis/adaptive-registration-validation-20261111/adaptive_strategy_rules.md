## 探索後の規則（Validation 層。v1.0 で実装する候補）

| 状況 | 推奨する判定 |
|---|---|
| 画像の top-1 と核の top-1 が 40 µm 以内で一致し、SAME が確定し、核ゲートに合格 | ACCEPTED（現行と同じ） |
| 画像と核が一致し、DIFFERENT で、象限 ≥3/4 | TISSUE_LEVEL（肯定の証拠が 2 つ。目視確認を推奨） |
| 画像だけ UNIQUE、象限 ≥3/4、核とは一致しない | TISSUE_LEVEL（**要目視**。鏡像の誤採択はこの形だった） |
| 画像が UNIQUE、象限の一部が判定不能（視野外や組織が少ない） | 新しい状態 `TISSUE_LEVEL_PARTIAL` を提案。判定可能な象限の中での一致率で判定する。v1.0 で検証してから決める |
| AMBIGUOUS で、正しい候補が top-k に入っている可能性 | `AMBIGUOUS` のまま、上位候補を UI で比較し、手動で選べるようにする（ASSISTED） |

## 4 つの問いへの答え（現時点。2 サンプルが根拠）

| 問い | 答え |
|---|---|
| 組織画像を優先すべきスライド | 両方の画像があり、IF の非核チャンネル（occ）が核と相関しない（≤0.5）。cleft の強さが約 0.2 以上。異なる切片（核が対応しない）。8_6 型 |
| 核点群が有効なスライド | **同一切片が来歴で確定**していて、核の密度が十分なもの。ただし視野が小さいと、誤った位置を UNIQUE にすることがある（6_2 の IF を半分にしたケース）ので、核ゲートが必須 |
| 複数の手段を併用すべき条件 | **常に併用する**（どちらが当たるかは事前に分からない）。両方が一致することが、最も強い独立の証拠 |
| 自動採択を保留すべき条件 | 切片の関係が UNKNOWN または CONFLICT、TISSUE_LEVEL、FOV の比 ≥10、部分重なりで象限が判定不能、手段どうしの CONFLICT、ASSISTED |
