# Contextual UOT cost ablation

Controlled, candidate-fixed analysis of how contextual ground-cost components
change unbalanced-OT transport mass and correspondence decisions.

Every A0--A6 condition uses the exact 30 candidate indices generated by the
Full contextual method for that dataset/case. Coordinates, source/target
masses, solver settings, convergence tolerance, and classification thresholds
are frozen. Only the ground-cost composition changes.

Run:

```bash
/home/noa.ganeko/miniconda3/envs/cell-rg/bin/python \
  analysis/contextual-uot-cost-ablation-20261008/run_cost_ablation.py
```

This is a matching/transport experiment only. It does not reconstruct a
deformation field or modify Workflow C, Workflow D, UI, or safety settings.
